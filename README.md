# 大溪國中 AI 智慧社團選社與適性導航系統

> 本專案為桃園市「AI好幫手：智慧協作工具徵選與應用計畫（智慧行政組）」之全新成果。  
> 服務學校：桃園市立大溪國民中學 ｜ 開發團隊：游貿仁 老師

---

## 🌟 系統亮點與參賽特色

1. **Gemini 智慧適性選社顧問（生涯探索適性導航）**：
   - 告別過去「盲選、跟風、搶熱門」的盲點。
   - 學生只需用口語描述興趣特質（例如「我喜歡動手組裝、對寫程式有一點好奇，但不喜歡曬太陽跑步」），Gemini 自動比對全校社團課程大綱，給予契合度最高之 Top 3 社團推薦、適配分析理由與溫暖啟發小語。
   - 具備**去識別化防護機制**，絕不傳送學生姓名或身分證號至大模型。
   - 具備**智慧規則備援引擎**，無須 API Key 亦能精準媒合。

2. **公平性雙軌選社模式（即時報名 / 多志願 AI 智慧適性分發）**：
   - **即時選填模式**：採 `LockService` 併發鎖與原子操作，杜絕超額與重複報名。
   - **多志願序模式**：學生登記 1~3 志願，後台一鍵執行平衡分發演算法，達到前三志願滿足率最大化（通常高達 95% 以上），避免傳統搶名額造成的網路塞車與怨懟。

3. **智慧行政減量（一鍵生成 Google Docs / Sheets 報表）**：
   - **一鍵產出社團點名簽到單**：自動在 Google 試算表建立格式化簽到簿分頁，包含社團名稱、指導老師、活動地點、各班學生清單與簽到格。
   - **一鍵產出成果手冊 (Google Docs)**：自動整合各社團特色、指導老師、開課人數與核心素養架構，免去數十小時排版負擔。
   - **未選社名單一鍵檢核與 AI 催繳文案**：自動過濾未選社學生並擬妥給導師的溫馨提醒訊息。

4. **現代化 UI/UX 與離線預覽支援**：
   - 響應式介面，支援手機、平板與桌機。
   - 內建**本機離線 Mock 模式**，直接雙擊 `index.html` 即可完整體驗與評審展示。

## 🚀 獨立部署至 Google 雲端步驟

### 步驟 1：建立 Google Apps Script 專案
1. 開啟 [Google Apps Script](https://script.google.com/)。
2. 點擊「新增專案」，將專案命名為：`大溪國中AI智慧社團選社系統`。

### 步驟 2：貼入程式碼
1. 將本目錄中的 [Code.gs](file:///f:/1150909---自主學習上傳空間網站/ai-club-system/Code.gs) 內容貼入編輯器的 `Code.gs`。
2. 在左側點擊「＋」新增 HTML 檔案，命名為 `index`（小寫），貼入 [index.html](file:///f:/1150909---自主學習上傳空間網站/ai-club-system/index.html) 的內容。
3. 點選左側「專案設定 ⚙️」，勾選「在編輯器中顯示 appsscript.json 資訊清單檔案」，將 [appsscript.json](file:///f:/1150909---自主學習上傳空間網站/ai-club-system/appsscript.json) 內容貼入並儲存。

### 步驟 3：初次授權與資料庫試算表初始化
1. 在編輯器上方函式下拉選單中選擇 `setup` 或 `ensureSheetExists`，點擊「執行」。
2. 依提示完成 Google 帳號授權（允許存取 Spreadsheets、Docs 與網路請求）。
3. 執行完成後，系統會自動在您的雲端硬碟建立「大溪國中AI社團選社資料庫」試算表，內建三大工作表（`社團設定`、`學生名冊`、`系統設定`）與示範社團資料！

### 步驟 4：發布為網頁應用程式 (Web App)
1. 點擊右上角「部署 → 新增部署作業」。
2. 種類選擇「**網頁應用程式**」。
3. 說明填入：`AI智慧社團選社系統 v1.0`。
4. 執行身分選擇：「**我**」。
5. 誰可以存取選擇：「**所有人**」（讓學生免登入校務帳號即可由手機選填）。
6. 點擊「部署」，複製以 `/exec` 結尾的正式網址，即可發布給學生與老師使用！

## 🌐 GitHub Pages ⇄ Google 試算表（前後端分離，免 Google 灰色警告列）

前端 `index.html` 可直接放在 GitHub Pages，透過 Apps Script 的 `doPost` API 讀寫您的 Google 試算表；**同一份 `index.html` 也能貼進 Apps Script 內嵌使用**，程式會自動判斷：

| 偵測結果 | 模式 | 說明 |
| :--- | :--- | :--- |
| 在 Apps Script 網頁內開啟 | `gas-native` | 以 `google.script.run` 直連試算表 |
| 在 GitHub Pages 且 API 可用 | `remote` | 以 `fetch`（`text/plain` 簡單請求，無 CORS 預檢）呼叫 `/exec` |
| API 尚未部署／離線／手動切換 | `mock` | 內建展示資料庫，並顯示「發表展示導覽列」 |

頁首右上的連線標籤可隨時點開：貼上 `/exec` 網址即可改連其他學校的後端，輸入 `mock` 則強制展示資料庫（現場沒網路時使用）。

### 讓 GitHub Pages 連上試算表（一次性）
1. 把最新的 [Code.gs](Code.gs) 貼進 Apps Script（內含 `doPost` API 閘道與社團管理 API）。
2. `CONFIG.DEFAULT_SPREADSHEET_ID` 預設綁定本校資料庫；**他校複製請改成自己的試算表 ID**，或在「專案設定 → 指令碼屬性」新增 `SPREADSHEET_ID`。
3. 「部署 → 管理部署作業 → 編輯 → 版本：新版本」重新部署（執行身分：我；存取權：所有人）。**未建立新版本，`/exec` 仍會執行舊程式碼。**
4. 重新整理 GitHub Pages，頁首標籤變成「☁️ 已連線 Google 試算表」即成功。

## ⚙️ 教師管理後台使用說明

1. 點擊頁首「⚙️ 訓育組管理」。
2. 輸入管理密碼（首次部署預設為 `admin888`，**首次登入會強制修改**，新密碼至少 8 碼）。
3. 進入管理中心後，您可以：
   - 查閱全校選社即時進度，點擊「待分發／未選人數」展開未選學生明細。
   - **🗂️ 社團資料管理**：直接在網頁新增／編輯／刪除社團，修改即時寫入試算表（已有學生錄取的社團不可刪除或更名）。
   - 點擊「🤖 執行 AI 多志願公平適性分發」，先檢視預覽統計再確認套用。
   - 點擊「📊 一鍵產出各社團點名簽到單」，自動建立試算表簽到冊。
   - 點擊「📄 一鍵生成社團手冊與行政成果報告」，自動由 Gemini 排版生成 Google Docs。
   - 隨時調整選社標題、起訖時間、選社模式（即時搶額／三志願分發）、Gemini API Key 與導師通行碼。

## 🧪 單元測試與本機驗證

本系統具備完整後端單元測試，執行方式：
```bash
node --test ai-club-system/tests/club_backend.test.cjs
```
測試涵蓋 12 大面向：
- 學生名冊與班級清單載入、身分驗證（末 4 碼與全碼檢核）
- 即時選填報名、防超額防重複併發鎖定、班級防抱團上限
- 開放期間重新改選（釋出名額）與保障生不可退選
- Gemini AI 智慧選社顧問、PII 遮蔽與備援規則引擎
- 多志願序登記、抽籤序、預覽／確認兩段式分發
- 教師後台驗證、導師通行碼、一鍵行政報表
- `doPost` API 白名單路由與錯誤封裝、社團管理 API（含公式注入防護）
